# 商品CSVの三者比較

[無料のブラウザー版を開く](https://hitocase.itch.io/catalog-three-way-check)

古い商品CSVを上書きする前に、編集前の基準・更新直前の現在・自分の編集案を、明示した不変キーで比べる確認ツールです。同じセルが別の値へ変更された競合、Vendorの明示空欄、Option1～3 Valueの変更を確認します。生成AIを制作補助に使っています。Shopify公式・提携ツールではありません。

この配布は、入力の対応付けや比較規則を実装から確認したい担当者向けです。配布ページの無料版と同じ6ファイルを掲載しています。機能・計算を変えた版ではありません。

## 架空の2商品で試す

無料版で「架空の2商品で試す」を選ぶか、次のCSVを対応する3欄へ貼り付けます。キー見出しは `row_key` です。現在CSVの取得日時は、架空例なら架空だと分かる注記を入れ、3枚の対応を確認して比較します。

基準：

```csv
row_key,Price,Vendor,Option1 Value
001,1000,Acme,Red
002,2000,Beta,Large
```

現在：

```csv
row_key,Price,Vendor,Option1 Value
001,1200,Acme,Red
002,2200,Beta,Large
```

編集案：

```csv
row_key,Price,Vendor,Option1 Value
001,1100,,Blue
002,2000,Beta,Large
```

`001` のPriceは1000→1200と1000→1100が競合します。Vendorの空欄とOption1 Valueの変更も注意点になります。`002` のPriceは現在だけが2200になっています。「現在だけ変更」は保持を検討する候補で、Shopifyへの実インポートが自動で保持するという意味ではありません。古い値2000を実際にインポートすれば、現在値を消す可能性があります。

## 自分のCSVの準備

3枚で同じ商品・variantを同じ不変キーに対応付けてください。SKUやHandleの一意性を仮定した自動名寄せはしません。必要なら、事前に複合キー列を作ります。基準と現在の行キー集合・列集合は一致させ、含めた空欄は空文字として明示します。省略した列と明示空欄、編集案にない行は別に扱います。

画像専用行、新規商品追加、行構成が変わるCSVは対象外です。Shopifyの未加工exportをそのまま扱える保証はありません。更新直前の現在CSVを取り直す負担や、その取得後の鮮度は検証できません。キーや空欄の意味を推定しません。

各1000データ行・50列・UTF-8換算500KBまで。行・列・文字数の組合せにより、これより小さな入力でも容量エラーになる場合があります。エラー時は比較を完了していません。画面は変更セル最大200件、確認票には全件を含みます。

## 無料の範囲と別の相談

自分の3枚の比較・結果表示・全件確認票のコピーまで無料で完結します。購入・相談・登録は不要です。入力はブラウザー内のメモリで処理し、外部送信や自動保存は行いません。顧客情報・秘密情報・認証情報を入力しないでください。

自社CSVの対応キー作成、列の対応付け、反復用の入力形式調整が必要な場合だけ、[配布ページ](https://hitocase.itch.io/catalog-three-way-check)の公開コメントで「対象列・件数・必要な出力」の概要を相談できます。これは個別の有料作業を見積もる入口で、価格・納期・受託は未確約です。ストア接続・実インポート・認証情報の受渡しは対象外です。元ファイルや秘密情報を公開コメントやIssueに貼らないでください。

すべてのCSV制約・破壊的変更を検知するものではありません。競合0でも安全にインポートできる保証はありません。自動統合、Shopifyへの接続・書込み、修正済みインポートCSV出力は行いません。新しいvariant IDや取得後の鮮度を予測しません。

## ファイルと根拠

`index.html` をブラウザーで開きます。同じフォルダーに `style.css`、`business.js`、`model.js`、`app.js`、`README.txt` を置きます。インストールやAPIキーは不要です。

`business.js` は受領した計算coreを変更せず使用しています。`model.js` はCSV入力の検証・変換、`app.js` は結果表示と確認票コピーを担当します。ソースの公開は、第三者権利や再配布・再販売の包括的な許諾を新しく加えるものではありません。

[Shopify公式：商品CSVをインポートする際の上書きの注意点](https://help.shopify.com/en/manual/products/import-export/import-products)。非必須列の明示空欄と省略列、option値変更によるvariant IDへの影響が説明されています。本ツールが公式インポート全体を再現しているという意味ではありません。
